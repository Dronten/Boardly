Boardly is a collaborative Kanban board. Users can create boards, invite members by email, and organise work in lists and cards. Cards can be dragged within a list or between lists, and the order is saved on the server. Boards have two roles: admins manage the board, lists and members, and members create, edit, move and delete cards.
